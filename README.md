# 🚗 Tesla Stock Sales Analysis – Power BI Dashboard

## 📊 Project Overview

This project is an interactive **Tesla Stock Sales Analysis Dashboard** created using **Microsoft Power BI**.

The dashboard provides insights into Tesla vehicle sales, pricing, EMI, accidents, states, and autonomous driving systems (DAS).

## 🎯 Objectives

- Analyze Tesla vehicle pricing across different states.
- Compare EMI values by state.
- Analyze average and median vehicle prices.
- Understand accident vs. non-accident vehicles.
- Analyze pricing based on Driving Assistance Systems (DAS).
- Create an interactive and visually appealing Power BI dashboard.

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**
- **DAX**
- **Data Cleaning & Transformation**
- **Data Visualization**

## 📌 Dashboard Features

### Key Performance Indicators

- **Average Price:** 33.93K
- **Median Odometer:** 28.31K
- **Average EMI:** 529.37
- **Not Accident:** 91.58%
- **With Accident:** 8.42%

### Visualizations

- 💰 Sum of Price by State
- 💳 Sum of EMI by State
- 🚗 Average Price by DAS
- ⚠️ Accident vs. Non-Accident Analysis
- 📊 Interactive state-wise analysis
- 🔍 Driving Assistance System comparison
- 🚘 Tesla vehicle visual
